# AI-Playground 🚀
AI Playground is an interactive, AI-powered web application designed to explore and experiment with Google's Gemini AI. It enables users to generate interactive UI components, write clean code, create creative content, and analyze information using different AI model personas.

With features like AI App Builder, Code Assistant, Creative Writer, and Data Analyst, users can transform simple text prompts into useful AI-generated outputs through a clean and user-friendly interface.

 # Key Highlights✨
- 🤖 Multiple AI Personas
- 🛠️ Interactive App & UI Generation
- 💻 AI-Powered Code Assistance
- ✍️ Creative Writing & Content Generation
- 📊 Data Analysis & Insights
- ⚡ Quick Starter Prompts
- 📜 Prompt History Management
- 👁️ Interactive Preview & Formatted Responses
- 🔗 Google Gemini API Integration
